# DnD-API-Project
Command line application that allows users to create DnD 5e characters and spellbooks for these characters. 

-Automatically works out spell progression for various spellcasters and multiclassing.

-Has persistant storage of characters, their classes, their spellcasting details, and their spells.

Future Features:

-Multiclassing stat requirements

-Wizard spell scribing

-Spell requirement implementation

Utilises the APIs from https://docs.dnd5eapi.co/, using the 2014 version for class details and the 2024 version for spells.
